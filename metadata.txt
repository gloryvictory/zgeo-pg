about=ZGeo-PG connects to a PostgreSQL database with the PostGIS extension and shows all spatial tables. In the "Connections" tab you enter host, port, database, user and password, then connect; the list of saved connections is kept in QGIS settings. The "Tables" tab lists spatial tables with the table comment, geometry column, geometry type, SRID, estimated row count, exact feature count, table size and spatial index details; the values are loaded in the background without blocking the interface. A filter narrows the list by name or schema. The "Statistics" tab builds charts by geometry type and schema. Lists and statistics tables can be exported to Excel with totals. The interface switches between Russian and English without restarting QGIS.
